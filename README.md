# Ziyi Xu — Personal Website

Website: https://megalovan.github.io/Ziyi_WEB/

This is a complete static website. All 28 files belong at the repository root; no folders, build, or installation are needed. Keep these filenames unchanged. The flat layout preserves the original images, local font, MathJax, languages, and interactive figures.

## Publish on GitHub Pages

1. Upload **all files in this folder** to the root of `Megalovan/Ziyi_WEB` and commit to `main`. Include the hidden `.nojekyll` file. Upload the files, not the ZIP.
2. Open **Settings → Pages → Build and deployment**.
3. Choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
4. Wait for the Pages deployment to succeed in **Actions**, then open the website above.

Future commits to `main` update the site automatically. The canonical URL is already set. Shared reading charts require a separate analytics service and are currently disabled.
