How to interpret this

Time is counted only while the tab is visible, its window has focus, and an interaction occurred within the last 60 seconds. Each moment is assigned to the most visible section. Paper time is a subset of section time. These are viewing estimates; they cannot establish whether someone actually read or understood the content.

The collector stores daily aggregates and short-lived hashed event receipts for retry deduplication. It does not store names, raw IPs, typed search text, pointer coordinates, session replays, or a per-visitor reading history. Browser opt-out, DNT, and GPC stop new collection. Delivery is best effort.

Reports require the Worker’s ADMIN_TOKEN. This HTML page is publicly accessible, but report data is protected by the API. The token stays in memory and is never included in the URL or local storage.
